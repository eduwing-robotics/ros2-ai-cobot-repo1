# FR5 디지털 트윈 최종 목표 기능 리스트

## 최종 목표

사용자가 Unity 화면에서 작업 셀과 부품 상태를 확인하고 Pick & Place 목표를 지정하면, MoveIt이 도달 가능성과 충돌을 검증해 경로를 생성하고, ROS/FR5 제어기가 승인된 작업을 실행한다. 실행 결과와 실제 센서 상태는 다시 Unity 디지털 트윈에 반영되어야 한다.

## 전체 레이어 구조

```text
┌───────────────────────────────────────────────┐
│ Layer 1. 사용자·UI 시각화                    │
│ 작업 지정 · 경로 미리보기 · 상태 · 알람      │
├───────────────────────────────────────────────┤
│ Layer 2. Unity 작업 제어                     │
│ 작업 상태 머신 · 좌표 관리 · 실행 인터록     │
├───────────────────────────────────────────────┤
│ Layer 3. Unity 디지털 트윈                   │
│ 로봇 · 부품 · 충돌 객체 · 파지 상태          │
├───────────────────────────────────────────────┤
│ Layer 4. ROS 통신                            │
│ Topic · Action · Service · TF · Watchdog     │
├───────────────────────────────────────────────┤
│ Layer 5. MoveIt 모션 계획                    │
│ IK · 충돌 검사 · 궤적 계획 · Planning Scene  │
├───────────────────────────────────────────────┤
│ Layer 6. 실기·센서·안전                      │
│ FR5 제어기 · 그리퍼 · 카메라 · 비상정지      │
├───────────────────────────────────────────────┤
│ Layer 7. 데이터·검증                         │
│ 설정 · 로그 · 캘리브레이션 · 테스트          │
└───────────────────────────────────────────────┘
```

---

## Layer 1. 사용자·UI 시각화 레이어

사용자가 직접 보고 조작하는 영역이다.

| 기능 | 비고 |
|---|---|
| 3D 작업 셀 표시 | FR5, 그리퍼, 작업대, 부품, 장애물과 안전 영역을 표시한다. |
| 실기·시뮬레이션 모드 표시 | 실제 장비에 명령이 전달되는 상태인지 항상 명확하게 구분한다. |
| 부품 선택 | 3D 화면 또는 목록에서 작업할 부품을 선택한다. |
| Pick 위치 지정 | 부품의 Pick 위치와 접근 방향을 3D 마커로 지정한다. |
| Place 위치 지정 | Place 위치와 놓을 방향을 3D 마커로 지정한다. |
| 목표 Pose 편집 | XYZ와 RPY 값을 직접 입력하거나 3D 핸들로 수정한다. |
| TCP 및 좌표축 표시 | 현재 TCP, 목표 TCP와 기준 좌표계를 시각적으로 표시한다. |
| 경로 계획 요청 | 선택한 Pick & Place 작업을 MoveIt에 전달한다. |
| 경로 미리보기 | 계획된 TCP 경로와 로봇 자세를 선 또는 고스트 모델로 재생한다. |
| 계획 결과 표시 | 성공, 실패, 충돌, 도달 불가와 실패 이유를 표시한다. |
| 작업 실행 확인 | 검증된 경로와 대상 부품을 확인한 뒤 실행한다. |
| 실행 제어 | 실행, 일시정지, 재개와 취소 기능을 제공한다. |
| 로봇 상태 표시 | J1~J6 각도·속도, TCP Pose, 그리퍼 상태를 표시한다. |
| 통신 상태 표시 | ROS, MoveIt, FR5, 카메라와 Watchdog 상태를 표시한다. |
| 작업 단계 표시 | 대기, 계획, 접근, Pick, 이동, Place, 복귀 단계를 표시한다. |
| 충돌·안전 경고 | 충돌 객체, 안전 영역 침범과 실행 불가 조건을 강조한다. |
| 카메라 화면 | ROS 카메라 영상과 부품 검출 결과를 표시한다. |
| 이벤트·알람 목록 | 통신 오류, 계획 실패, 작업 완료와 사용자 조작 기록을 표시한다. |
| 카메라 전환 | Robot View, Global View와 필요 시 작업 셀 프리셋을 제공한다. |

## Layer 2. Unity 작업 제어 레이어

화면 입력을 실제 작업 요청으로 바꾸는 Unity 내부 비시각 로직이다.

| 기능 | 비고 |
|---|---|
| 작업 상태 머신 | `Idle → Editing → Planning → Preview → Executing → Complete/Failed` 흐름을 관리한다. |
| Pick & Place 작업 모델 | 대상 부품, Pick Pose, Place Pose, 접근·후퇴 Pose와 작업 옵션을 묶어 관리한다. |
| 명령 유효성 검사 | 목표 누락, 잘못된 수치, 중복 실행과 허용 범위 이탈을 차단한다. |
| 좌표 변환 | Unity 좌표를 ROS 좌표로 변환하고 m/mm, deg/rad 단위를 통일한다. |
| 실행 인터록 | 통신 정상, 계획 성공, 충돌 없음과 사용자 승인 조건을 확인한다. |
| 모드 관리 | Shadow, Manual, Simulation과 Real 실행 권한을 분리한다. |
| 명령 중복 방지 | 실행 중 추가 실행 요청 또는 오래된 계획의 실행을 차단한다. |
| 오류 복구 | 계획 실패, 통신 단절과 실행 중단 후 재계획 또는 안전 복귀를 지원한다. |
| UI 상태 동기화 | 작업 상태에 따라 사용할 수 없는 버튼과 입력을 비활성화한다. |

## Layer 3. Unity 디지털 트윈 레이어

가상 작업 셀의 현재 상태와 물리 표현을 관리한다.

| 기능 | 비고 |
|---|---|
| FR5 URDF 모델 | 링크, 관절 제한, 질량, 관성과 충돌 형상을 Unity ArticulationBody에 반영한다. 현재 기본 구현됨. |
| 실기 자세 동기화 | `/joint_states`를 받아 Unity 로봇 자세를 갱신한다. 현재 기본 구현됨. |
| 부품 상태 관리 | 부품 ID, Pose, 선택 여부, 작업 상태와 파지 상태를 관리한다. |
| 장애물 상태 관리 | 작업대, 장비와 안전 영역의 Pose 및 활성 상태를 관리한다. |
| 가상 그리퍼 | 열림 정도, TCP와 파지 상태를 Unity 모델에 반영한다. 현재 시각 조작만 구현됨. |
| Attach·Detach | Pick 성공 시 부품을 TCP에 부착하고 Place 성공 후 분리한다. |
| 계획 궤적 재생 | MoveIt 결과를 실기 명령 없이 Unity에서 먼저 재생한다. |
| 실제·계획 자세 비교 | 실제 로봇과 계획 경로의 차이를 표시할 수 있는 상태 데이터를 제공한다. |
| 충돌 시각화 데이터 | 충돌 객체와 충돌 지점을 UI에서 표시할 수 있도록 전달한다. |

## Layer 4. ROS 통신 레이어

Unity와 ROS2 시스템 사이의 메시지 전달과 연결 상태를 관리한다.

| 기능 | 비고 |
|---|---|
| ROS-TCP 연결 | Unity와 ROS2 Endpoint 연결, 재연결과 종료 처리를 관리한다. |
| JointState 구독 | `/joint_states`를 수신하고 이름, 단위, 시간값을 검증한다. 현재 구현됨. |
| 카메라 송수신 | Unity 가상 카메라 발행과 ROS 카메라 영상 수신을 지원한다. 현재 기본 구현됨. |
| TF 수신·변환 | `world`, `robot_base`, `tool`, `camera`, `object` 프레임 관계를 동기화한다. |
| MoveIt 계획 요청 | 목표 Pose와 계획 옵션을 Action 또는 Service로 전송한다. |
| 계획 결과 수신 | 성공 여부, 오류 코드와 RobotTrajectory를 Unity로 전달한다. |
| 실행 요청·취소 | 승인된 궤적의 실행과 취소를 Action으로 요청한다. |
| 그리퍼 명령 | 열기, 닫기와 목표 폭 명령을 보내고 실기 상태를 수신한다. |
| Planning Scene 갱신 | 부품과 장애물의 추가, 이동, 제거 및 Attach 상태를 MoveIt에 전달한다. |
| Heartbeat·Watchdog | 통신 지연과 단절을 감지하고 실행을 차단한다. 현재 Unity 수신 감시는 기본 구현됨. |
| 메시지 시간 관리 | 오래된 센서값과 순서가 뒤바뀐 응답을 거부한다. |

## Layer 5. MoveIt 모션 계획 레이어

Unity가 지정한 목표를 로봇이 안전하게 수행할 수 있는 경로로 변환한다.

| 기능 | 비고 |
|---|---|
| IK 계산 | 목표 TCP Pose에 대응하는 J1~J6 자세를 계산한다. |
| 도달 가능성 검사 | 작업 공간, 관절 제한과 특이점 조건을 검사한다. |
| 충돌 검사 | 로봇 자체, 부품, 작업대와 장애물의 충돌을 검사한다. |
| 경로 계획 | 현재 자세에서 목표 자세까지 충돌 없는 궤적을 생성한다. |
| 시간 파라미터화 | 관절 속도와 가속도 제한에 맞춰 실행 시간을 계산한다. |
| Pick 접근·후퇴 계획 | Pick 전 접근과 파지 후 후퇴 경로를 생성한다. |
| Place 접근·후퇴 계획 | Place 접근과 부품 분리 후 후퇴 경로를 생성한다. |
| Planning Scene 유지 | Unity 및 센서에서 전달된 작업 셀 충돌 환경을 유지한다. |
| Attach·Detach 반영 | 파지된 부품을 로봇 일부로 취급하고 놓은 뒤 환경 객체로 복구한다. |
| 계획 결과 반환 | 궤적, 예상 시간, 오류 코드와 실패 이유를 Unity에 반환한다. |
| 재계획 | 환경 또는 시작 자세가 바뀌었을 때 기존 계획을 폐기하고 다시 계산한다. |

## Layer 6. 실기·센서·안전 레이어

실제 FR5와 주변 장비를 움직이고 실물 상태를 측정한다.

| 기능 | 비고 |
|---|---|
| FR5 궤적 실행 | MoveIt/ROS에서 전달한 JointTrajectory를 실제 제어기가 실행한다. |
| 관절 피드백 | 실제 각도, 속도, 가능하다면 토크·오류 상태를 ROS로 발행한다. |
| 실기 그리퍼 제어 | 목표 폭 또는 열기·닫기 명령을 실행하고 완료 여부를 반환한다. |
| 부품 위치 검출 | 카메라 또는 센서로 실제 부품 Pose를 측정한다. |
| 캘리브레이션 기준 제공 | 로봇 베이스, 작업대와 카메라 간 기준 좌표를 제공한다. |
| 하드웨어 안전장치 | 물리 비상정지, 안전 PLC, 속도 제한과 작업 영역 제한을 담당한다. |
| 실행 실패 감지 | 보호 정지, 그리퍼 실패, 부품 미검출과 제어기 오류를 ROS에 전달한다. |
| 수동 복구 | 자동 복구가 불가능한 경우 안전한 수동 조작 절차를 제공한다. |

## Layer 7. 데이터·검증 레이어

설정 유지, 문제 추적과 시스템 신뢰성 검증을 담당한다.

| 기능 | 비고 |
|---|---|
| 작업 설정 저장 | Pick/Place Pose, Home Pose, 속도와 작업 옵션을 저장·불러온다. |
| 작업 셀 설정 저장 | 로봇, 작업대, 카메라와 장애물 배치를 저장한다. |
| 캘리브레이션 데이터 저장 | 좌표 변환 행렬, 측정 시각과 버전을 관리한다. |
| 이벤트·명령 로그 | 계획, 실행, 취소, 오류와 사용자 확인 이력을 기록한다. |
| 실행 결과 저장 | 작업 시간, 계획 대비 실제 오차와 성공 여부를 기록한다. |
| 통신 테스트 | ROS 연결, Topic, Action, Service와 TF 상태를 점검한다. |
| 좌표 변환 테스트 | Unity↔ROS 왕복 변환과 단위 변환을 검증한다. |
| 모션 계획 테스트 | 정상, 도달 불가와 충돌 사례의 결과를 검증한다. |
| 안전 조건 테스트 | 통신 단절, 오래된 계획, 실행 중 중복 명령과 정지 처리를 검증한다. |
| 시뮬레이션 사전 검증 | 실기 실행 전 동일 작업을 Unity와 MoveIt 환경에서 재현한다. |

## 최종 작업 흐름

```text
부품 위치 입력 또는 센서 검출
        ↓
Unity에서 Pick·Place 목표 지정
        ↓
ROS를 통해 MoveIt 계획 요청
        ↓
IK·관절 제한·충돌 검사 및 궤적 생성
        ↓
Unity에서 경로 미리보기와 사용자 승인
        ↓
FR5 및 그리퍼 실행
        ↓
JointState·센서 결과를 Unity 트윈에 반영
        ↓
작업 완료 또는 오류 복구
```

## 구현 단계

| 기능 | 비고 |
|---|---|
| 1단계: 계획 MVP | Pick/Place 목표 지정, MoveIt 계획 요청, 경로 미리보기와 계획 결과 표시를 완성한다. |
| 2단계: 가상 작업 완성 | Unity 부품 Attach/Detach, 작업 상태 머신과 시뮬레이션 실행을 완성한다. |
| 3단계: 실기 실행 | FR5 궤적 실행, 실기 그리퍼, 실행 취소와 안전 인터록을 연결한다. |
| 4단계: 실제 환경 동기화 | 카메라 부품 검출, TF와 작업 셀 캘리브레이션을 연결한다. |
| 5단계: 운영 기능 | 로그, 설정 저장, 오류 복구와 작업 결과 분석을 추가한다. |
