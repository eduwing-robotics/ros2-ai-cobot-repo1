# Unity UI 책임과 화면 구조

Unity UI는 작업자가 생산 상태를 이해하고 안전한 다음 행동을 선택하도록 돕는 표현 계층입니다. 생산 상태를 직접 만들거나 DB와 설비 구현을 소유하지 않습니다.

## 화면별 결정

| 화면 | 사용자가 내려야 할 결정 |
|---|---|
| RUN | 현재 작업이 정상적으로 진행 중인지, 개입이 필요한지 판단 |
| JOBS | 제품과 목표 PASS 수량으로 작업을 등록하고, 작업 상태에 따라 실행·취소·검사 기록 확인을 선택 |
| INSPECT | 검사 결과와 근거를 확인하고 후속 조치를 판단 |
| MANUAL | 현재 모드와 안전 조건 안에서 수동 목표를 미리보기로 확인 |
| SETUP | 연결·설비 관측·좌표 보정과 작업 설정 근거를 확인하고 운전 전 필요한 조치를 판단 |

RUN 트윈은 전체·기판·조립부·부품 트레이 시점과 드래그 회전·이동·휠 확대를 제공합니다.
기판·조립부 시점은 표시 중인 기판을 우선하고, 기판이 없으면 설정된 투입 기준 위치를 봅니다.
트레이 시점은 이동 중 부품 대신 고정 공급 위치를 중심으로 봅니다.
기준 위치는 현재 관측과 구분하며, 선택 시 위치를 고정하고 자동 추적하지 않습니다.
트윈 확대 중에도 공통 알람을 유지하고, 페이지를 나가면 카메라 자세와 표시 영역을 복원합니다.
관측 영상은 하나를 선택해 보거나 분할로 비교하며 원본 비율을 유지합니다.

시작 화면은 RUN입니다. JOBS에서 운전 현황 또는 선택한 Job의 검사 기록으로 이동할 수 있습니다.
MANUAL은 현재 Ghost 목표 미리보기만 제공하며 실동작 적용과 그리퍼 개폐는 차단합니다.

한 화면은 하나의 대표 결정을 중심으로 구성합니다. 다른 화면의 책임을 복제해 여러 곳에서 같은 상태를 수정하지 않습니다.

## 데이터 경계

- 로봇과 조립 진행은 주입된 runtime 계약에서 읽습니다.
- 제품, 재고, Job, 검사와 품질 정보는 MainServer를 통해 조회합니다.
- UI는 DB, 구체 Mock/Real 구현과 설비 통신을 직접 호출하지 않습니다.
- UI에 보이는 진행 상태는 표현용이며 생산 상태의 원본이 아닙니다.
- 데이터가 없거나 오래됐거나 샘플이면 그 상태를 명확히 표시합니다.

## 자동과 수동

자동 조립은 Scenario의 단일 공개 진입점을 사용합니다. 수동 조작은 별도 저수준 제어 계약을 사용하며 자동 공정 순서를 대신하지 않습니다.

Mock과 Real 선택은 RobotMaster가 담당합니다. 화면과 Scenario는 구체 구현을 검사하거나 캐스팅하지 않습니다.

## 안전 경계

- 요청 수락을 완료로 표시하지 않습니다.
- 실제값과 목표값을 구분합니다.
- 위험 조작보다 운전 모드, 연결 상태와 제한 조건을 먼저 보여줍니다.
- 지원되지 않거나 확인할 수 없는 Real 동작은 비활성화하고 이유를 표시합니다.
- 화면의 STOP과 확인 동작은 물리 E-Stop과 안전회로를 대체하지 않습니다.
- 실패와 timeout은 숨기지 않고 사용자가 취할 수 있는 다음 행동과 함께 표시합니다.
- 현재 관절·TCP·그리퍼 값은 기존 로봇 상태의 수신 유효성 기준을 통과할 때만 표시합니다. 오래된 알람은 마지막 수신 이력으로 구분합니다.
- 그리퍼 개방률은 파지 여부나 실측 거리로 환산하지 않습니다. 수신 경과 시간과 로컬 관절 표시 범위는 설비 안전 한계가 아닙니다.
- 누적 조립 수량은 슬롯별 장착 이력이 아닙니다. 진행 분모는 실행 피드백을 사용하고 슬롯 칸은 트윈 구성으로 표시합니다.
- 재고는 조회 당시 DB 기록이며 실행 요청 가능은 설비 준비 완료를 뜻하지 않습니다. 검사 이력이 없으면 무불량으로 판정하지 않습니다.

시각 표현 원칙은 [HMI 화면 설계](ui-design.md)를 따릅니다.

## SETUP 조회 범위

SETUP은 공통 셸의 MainServer·DB·Sequencer 연결 판정을 재사용하고, 주입된 로봇·영상·보정 상태를 표시합니다.
제품·레시피는 마지막 조립 피드백의 Job을 MainServer에서 조회한 값이며 다음 작업의 적용 설정을 보장하지 않습니다.
트윈 슬롯 구성은 제품 레시피와 일치 검증된 결과가 아닙니다. 조회 실패 시 이전 제품 정보를 현재 정보처럼 표시하지 않습니다.

설비 전체 준비·reset 완료와 레시피 사전 검증 결과는 확인할 수 없으므로 연결 정상만으로 운전 가능을 표시하지 않습니다.
보정은 트윈 배치 반영 상태와 경과 시간을 표시하며 과거 반영 이력을 현재 설비 보정의 유효성으로 해석하지 않습니다.
페이지 종속 영상 수신기가 비활성이면 해당 상태를 명시합니다.
설정 변경·reset·재보정 명령과 안전 상한 편집은 제공하지 않습니다.
