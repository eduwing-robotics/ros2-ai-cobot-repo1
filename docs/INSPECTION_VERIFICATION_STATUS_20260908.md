## 실행 및 자료 보존

이번 종합 점검에서는 촬영·학습·모델 승격·서버 재시작·로봇/컨베이어 이동·DB 쓰기를 하지 않았다.
실제 검증 사진은 각 API 검사 디렉터리의 validation_provenance.json으로 학습 제외 처리했다.
audit_prospective_session.py로 명시적인 9개 대상 사례와 원본 해시를 다시 확인할 수 있다.

넓은 디렉터리 수집을 처음 잘못된 PatchCore 환경으로 실행해 YOLO 의존성 오류가 있었고,
Segmentation 전용 .venv_obb에서 54개를 통과했다. 보조 실행 파일 *_test.py는 일반 단위
테스트 수집 대상이 아니므로 test_*.py로 범위를 명시해 93개를 검증했다. 보조 실행 파일
전체가 검증됐다고 주장하지 않는다.
