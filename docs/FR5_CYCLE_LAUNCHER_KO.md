## 순서

1. 스택·현재 로봇 상태·Tool1 TCP·티칭점·D435 해상도/내부값을 검사한다.
2. PlaceCamera로 이동해 안정화 후 새 기판 관측 4개를 확인하고, 사진과 25개 배치 좌표를 저장한다.
3. TrayHome으로 이동해 검출기 관측20개 안정화를 기다린 뒤 부품별 연속4개 유효 관측을 수집한다. 미확정 좌표 변화는 해당 부품을 다시 수집하고, 확정된 좌표의 변화와 구분한다. 처음15초 + 추가3회(각15초, 총60초) 안에서 미검출·저신뢰도 부품만 재측정하며, 통과한 부품의 좌표는 유지한다. 일반20개 품질과 SMD5개 존재·형상·관측 안정성이 확인되면 저장한다. SMD의 먼 거리 신뢰도는 이 단계의 픽 허가에 사용하지 않으며, SMD 좌표는 근접검증 대기로 표시한다.
4. 같은 TrayHome에서 VRM 5개의 네 모서리를 부품별 새12프레임으로 측정한다. 기존 셀 번호를 유지하고 검증된 중심·각도만 반영한다. 별도 촬영 위치로 이동하지 않는다. 최대120초 내 모두 통과해야 일반 계획으로 진행한다.
5. 일반 20개 전체 계획과 실기 IK 경로를 검사한 뒤 GPU1 → HBM8 → PM4 → VRM5 → IND2 순서로 조립한다.
6. **일반 부품은 매번 집기 → 100mm 상승 → TrayHome → 해당 칸 제거 확인 → 기판 배치**를 수행한다. 기존 서로 다른 연속 3프레임 검사를 유지하며, 실패하면 기판 배치로 진행하지 않는다.
7. 일반 20개 전체 완료 기록과 계획 해시를 확인한 뒤 SMDView로 이동한다.
8. 사진을 저장하고 원본 RGB 24개 유효 프레임으로 SMD set1의 5개 중심·각도를 측정한다. 일시적 검출/품질 실패는 최대 4회 새로 측정한다. 기판은 처음 저장한 좌표를 사용한다.
9. SMD 계획과 실기 IK 경로를 검사한 뒤 5개를 조립한다. **SMD에는 TrayHome 파지 확인을 추가하지 않았다.**

‘한 번 촬영’은 촬영 자세에 한 번 이동해 좌표를 저장하는 단계다. 안정성 검사를 위한 여러 영상 프레임은 계속 사용한다. 일반 부품 파지 확인은 해당 셀 제거 검사이며 실제 보유·안착의 정밀 검사를 뜻하지 않는다.

## 점검과 기록

```bash
./run_fr5_cycle.sh --dry-run  # 설치·검토된 설정·순서만 확인; 접속/이동/IK 없음
./run_fr5_cycle.sh --check    # 현재 스택·로봇·카메라 준비 상태 조회; 이동 없음
```

인자를 생략하면 `--dry-run`과 같다. 실행 중 단계와 기존 부품별 진행 로그가 터미널에 표시된다. 새 실행마다 `runtime/assembly_cycles/날짜-시각/`에 다음을 남긴다.

- `board.jpg`, `tray.jpg`, `smd_view.jpg`: 각 촬영 위치에서 도착·안정화 후 받은 사진.
- `board_measurement.json`, `tray_measurement.json`, `smd_close.json`: 새 관측값.
- `snapshot.json`, `board_snapshot.json`, `tray_snapshot.json`: 계산에 사용한 기판/트레이 기준.
- `non-smd_plan.json`, `smd_plan.json`, 각 `*_run.json`: 계획과 부품별 동작 기록.
- `cycle.json`, `*_camera_stage.json`, 단계별 `.log`: 전체 진행, 카메라 경로 검사, 오류.
- `tray_retries.json`: 시도1~4, 확정수량, 미확정 부품·사유, 부품별 원본 관측 시각. 확정 관측은 새 프레임인 것처럼 시각을 바꾸지 않는다.

동일 런처의 중복 실행은 잠금으로 거부한다. 오류·Ctrl+C·촬영값 만료·완료 기록 불일치 후에는 다음 단계로 넘어가지 않는다. 동작 중 중단은 기존 실행기에 전달되어 `StopMotion()`을 시도한다. 촬영 재시도 소진/기하 불일치만으로 실패했고 새 로봇 피드백에서 정상 정지·촬영 자세가 확인되면 불필요한 `StopMotion()`은 생략한다. 피드백 미확보·동작 오류·Ctrl+C에서는 기존 정지 처리를 유지한다. 통신이 끊기면 소프트웨어 정지를 보장할 수 없으므로 현장 정지 장치를 사용한다. 실패 후 같은 명령을 다시 실행하면 처음부터 새 사이클이다. 이미 놓은 부품이 있는 상태에서는 재실행하지 말고 기록으로 중단 위치와 보유 상태를 확인한다.
