# 전체 부품 경로 검토 및 제한된 공통 보완 — 2026-09-10

## 문제와 수정

실행 cae2d56a-d064-4be0-b665-13e349b992e0의 사전 검사 실패를 읽기 전용 IK로 재현했다. HBM-01 배치 후 HBM-02 집기 상공으로 이동하는 J1 변화량은 95.162804도였으며 기존 구간 제한 95도를 초과했다. 대체 J6 기준값에서도 J1 결과는 같았다.

특정 슬롯을 예외로 넣거나 95도 제한을 올리지 않았다. 런처 사전 검사와 실제 Pick API가 공통으로 호출하는 preflight_route에 다음 대안 검사를 추가했다.

1. 기존 경로와 IK 선택을 먼저 그대로 계산한다. 통과하는 경로에는 경유점을 추가하지 않는다.
2. 동일 부품의 pre_pick_safe_vertical 다음에 바로 오는 pick_combined_xy_abc에서만 대안을 검토한다. 시작/목표 높이가 동일하고 350mm 이상이며, 하향 자세·TrayHome 방향 근처인 경우로 제한한다.
3. 관절 변화량이 기존 95도 제한을 초과하면 기존 TrayHome XY/자세와 해당 이동 높이를 사용하는 pick_via_trayhome_high를 한 번 검토한다.
4. 새 두 구간을 다시 IK 계산하고, 관절 여유 10도·J6 [-178,178]·구간 변화량 95도 검사를 그대로 적용한다. 실패하면 중단하며 추가 분할이나 제한 완화는 하지 않는다.
5. 새 경유점은 연속 블렌딩 목록에 넣지 않는다. 해당 목표에 정지한 후 다음 구간으로 진행한다. 기존 high_transfer 속도 설정을 그대로 사용한다.

기존 IND/SMD 방향 제어, 이미 분할된 경로, 부품 보유 후 이동, 카메라 이동, 접촉/하강/상승 경로는 자동 재작성하지 않는다. 따라서 모든 종류의 경로 오류를 자동 해결한다고 보장하는 변경은 아니다.
