# SMD 방향 검사 좌표계 수정

검출 모델은 섹션을 1200×720으로 변환한 영상에서 OBB를 출력한다. 현재 SMDView 섹션은 원본 1280×720 영상에서 약380×400px이므로 가로·세로 확대 비율이 다르다. 보정 영상 OBB의 장단비를 실제 방향 신뢰도로 사용하면 길쭉한 부품도 정사각형에 가깝다고 거부될 수 있다.

동일 검출 상자 비교에서 2·3·5번 장단비는 보정 영상1.238/1.304/1.278, 원본 영상2.280/2.403/2.335였다. 원본 상자는 유지된 상태에서 계산 좌표계만 바꾸어 확인했다.

`smd_terminal_axis.terminal_axis_from_source_obb`는 OBB 네 꼭짓점을 역호모그래피로 원본 영상에 복원하고, 그 좌표에서 긴 축과 장단비를 계산한다. 축 양끝은 다시 보정 영상 좌표로 변환하여 기존 Base 방향 계산 계약을 유지한다. 원본 이미지 픽셀 기준이며 3D 실물 장단비의 직접 측정은 아니다.

실시간 `smd_live_overlay.py`와 정밀 `capture_smd_close_target.py`가 같은 함수를 사용한다. 검출 모델·신뢰도·장단비 기준1.35·중심변동3.5px·각도시간변동3도·파지/배치 recipe는 변경하지 않았다. 원본에서 실제 정사각형인 박스는 확대된 화면에서 길쭉해 보여도 거부한다.

출력에 `axis_geometry_version=source_image_v1` 및 `axis_ratio_frame=source_image`를 기록한다. 재측정 병합기는 구버전과 신버전을 섞지 않는다. 기존 좌표·각도 관측은 새 촬영 없이 재사용하지 않는다.

검증: 비균등 확대와 회전 불변성, 좌표 왕복, 실제 정사각형 거부, 잘못된 호모그래피 거부, 구신 관측 혼합 금지, 기존 스냅샷 검증까지56테스트통과. 새24프레임2회측정에서 방향은모두통과; 첫측정2번중심변동3.898px로전체실패, 두번째는5개전체통과(최대중심변동2.753px,각도batchspan1.8923도). 검출반복성과 실물파지정확도는 구별한다. 이수정검증중로봇이동없음.
