# 포트폴리오 근거 기록

이 문서는 단순 작업 일지가 아니라 최종 포트폴리오의 문제 해결 사례와 정량
성과를 만들기 위한 근거를 누적한다.

## 프로젝트 한 줄 설명

FR5, Eye-in-Hand D435, 고정형 스마트폰 카메라와 ROS 2를 이용해 반도체
패키지형 전자모듈의 위치 보정·조립·검사를 수행하는 스마트 제조 셀.

## 현재까지의 대표 문제 해결 사례

### 1. 카메라 장착 오프셋을 좌표변환으로 해결

- 문제: D435가 그리퍼 중심축이 아닌 측면 브래킷에 장착되어 카메라 좌표를
  로봇 좌표에 단순 가산할 수 없음.
- 해결: Eye-in-Hand Hand-Eye Calibration과 명시적 homogeneous transform
  체인 도입.
- 검증: 고정 보드 독립 5자세에서 평균 `1.833 mm`, 최대 `2.981 mm`.

### 2. 관측 자세에 따른 위치 편차를 데이터 기반으로 진단

- 문제: 저장된 정면 자세에서는 맞지만 카메라 각도를 바꾸면 최대 약 3 mm
  위치 편차 발생.
- 접근: 보정값을 임의 수정하지 않고 동일 고정 마커의 Camera/Base 좌표,
  reprojection error, intrinsic, Flange/TCP pose를 CSV로 누적하는 멀티포즈
  검증 기능 구현.
- 구현 결과: 1920x1080 조건의 10개 자세에서 모두 마커 17/17, 코너 24/24를
  검출했다. 자세 내 프레임 흔들림은 최대 `0.053 mm`였지만 자세 간 Base
  좌표 범위는 X/Y/Z `1.524/0.939/3.004 mm`, 3D RMS는 `1.218 mm`, 최대는
  `2.172 mm`였다.
- 해석: 영상 검출은 안정적이지만 카메라 기울기 변화에 따라 특히 Z 오차가
  남는다는 점을 정량적으로 분리해 확인했다. 이 데이터를 근거로 무작정
  offset을 더하지 않고 Hand-Eye 회전 및 pose 추정 개선 단계로 진행한다.
- 추가 검증: 10자세에 맞춘 보정 후보는 해당 데이터에는 맞지만 독립 5자세
  최대 오차를 `7~12 mm`로 악화시켰다. 독립 검증을 통과하지 못한 후보를
  배포하지 않고 기존 결과를 보존함으로써 캘리브레이션 과적합을 차단했다.
- 원인 분리 실험에서 정면 자세 3회 복귀 편차는 최대 `0.053 mm`였지만 특정
  기울기에서는 `2.417 mm`가 발생했다. 이를 통해 로봇 반복정밀도/보드 이동과
  비전 pose·Hand-Eye 각도 의존 오차를 분리했다.
- 평면 IPPE 대안을 시험했지만 기울기 자세의 최대 reprojection error가 약
  `3.6 px`로 기존 방식보다 악화돼 품질 기준에서 자동 차단했다. 실패한
  알고리즘도 정량 기준으로 조기 중단하고 기록했다.
- 기존 보정 데이터가 640x480, 새 검증이 1920x1080이라는 실험 조건 차이를
  원본 이미지에서 추적했다. 이후 동일 1920 조건의 calibration/validation
  분리 원칙을 도입했다.
- 1920 독립 6자세에서 공장 intrinsic 사용 시 최대 `6.345 mm`였던 좌표
  일관성을 해상도별 intrinsic 재추정으로 `0.961 mm`, 새 Hand-Eye까지
  포함해 `0.753 mm`로 낮춘 비활성 후보를 만들었다. 활성값은 독립 검증과
  dry-run이 끝날 때까지 덮어쓰지 않는 배포 안전 절차를 적용했다.
- 초기 육안 접근 측정값의 신뢰도가 부족함을 인지하고, Tool 데카르트 조그를
  1 mm/0.5 mm 단위로 누적하는 정량 절차로 개선했다. 첫 유효 측정은 Tool
  XY `[-2.5, -2.5] mm`이며 반복 측정 전에는 offset을 하드코딩하지 않는다.
- 두 번째 관측 자세에서는 Tool XY `[-5.5, 0] mm`가 측정돼 단일 고정
  offset 가설이 성립하지 않았다. 같은 저장 자세 재방문 시험으로 비전의
  자세 의존성과 물리 측정 반복성을 추가 분리한다.
- 저장 자세 재방문 시 첫 측정 `[-2.5,-2.5] mm`가 동일하게 재현됐다.
  이를 통해 작업자 측정 변동이 아니라 관측 자세 의존 오차임을 실험적으로
  확인하고 TCP 임시 offset 적용을 배제했다.

### 3. 저해상도에서 발생한 ChArUco 불안정 진단

- 문제: 동일 위치인데 마커 검출이 깜빡임.
- 원인: 입력이 이전 안정 설정 1920x1080@15가 아닌 640x480@30으로 실행됨.
- 대응: 해상도·CameraInfo 일치 검사와 D435 고해상도 안정 실행 절차 관리.

## 데이터 품질 관리 사례

- intrinsic 전용 촬영 중 16번째에서 구도 오류를 발견해 잘못된 데이터에 맞춰
  계산을 진행하지 않고 전체 세트를 폐기 보관 후 재수집했다. 원본은 감사 가능한
  archive로 유지하고 활성 데이터만 초기화했다.
- 재수집 25장이 모두 검출 성공했더라도 라벨이 아닌 실제 픽셀 중심 분포를
  분석해 좌우 커버리지가 38~60%에 집중된 것을 발견했다. 낮은 reprojection
  RMS만 보고 채택하지 않고 비정상적으로 큰 왜곡계수를 근거로 가장자리 8장을
  추가 수집하도록 실험을 보완했다.
## 2026-08-12 — 캘리브레이션 과적합 진단 사례

- 중앙 위주의 영상으로 얻은 낮은 재투영 오차가 화면 가장자리에서는 유지되지 않는 현상을 정량 비교했다.
- 33장의 거리·화면 위치 분산 데이터로 내부 파라미터의 전체 화면 일반화를 확인했다.
- 내부 파라미터와 Hand-Eye를 같은 데이터에서 동시 최적화했을 때 발생할 수 있는 오차 상쇄를 독립 6자세 검증으로 발견했다.
- 안전상 새 후보를 즉시 로봇 이동에 적용하지 않고 기존 활성값을 유지했다.
## 2026-08-12 — Eye-in-Hand 25자세 데이터셋 구축

- 고정 ChArUco 보드에 대해 Base 평행 이동과 Tool RX/RY/RZ 양방향 회전을
  조합한 25자세 Eye-in-Hand 데이터셋을 구축했다.
- 수집 단계에서 해상도, 검출 코너 수, 재투영 오차, 자세 중복을 자동 검사했다.
- OpenCV Hand-Eye 방법별 결과를 독립 데이터로 비교하고, 최저 오차 후보도
  학습 자세 일관성이 충분하지 않으면 즉시 운영값으로 승격하지 않는 검증
  절차를 적용했다.
## 2026-08-12 — RGB 기하와 Depth 센서의 교차 검증

- RGB ChArUco solvePnP의 거리 스케일을 동일 카메라의 aligned depth로 독립
  검증하는 노드를 구현했다.
- 정면 자세 30프레임에서 두 방식의 Z 차이가 약 1.04 mm임을 확인하고,
  재투영 오차는 낮지만 실제 깊이가 약 12 mm 틀린 intrinsic 과적합 후보를
  안전하게 배제했다.
## 2026-08-12 — FR5 RGB-D 첫 실물 Pick 성공

- 10 mm 높이 검정 테스트 물체를 D435 RGB-D로 검출하고 FR5 Base 좌표로
  변환하여 안전 접근 및 실제 파지에 성공했다.
- ChArUco 기준 평면, aligned depth, 등록 부품 높이, 단계 이동, 저속 파지,
  10 mm 시험 상승을 결합한 안전 절차를 검증했다.
- 파지 후 로봇·그리퍼·충돌 오류가 모두 0임을 ROS 상태 토픽으로 확인했다.
- 발표 자료에는 검출 화면, 안전 접근 위치, 근접 중심 정렬, 들어 올린 장면,
  성공 후 상태 로그를 순서대로 제시할 수 있다.
## 2026-08-12 — 제조 셀 비전 구조 설계

- 단순 HSV 데모를 실제 조립 공정에 맞게 역할 분리했다: 기판 좌표는 Fiducial,
  부품 pose는 contour/minAreaRect, 거리는 aligned depth, 높이는 부품 recipe,
  최종 검사는 고정형 카메라 ROI 비교를 사용한다.
- 고정 공정의 사전 지식을 활용해 학습 데이터 수집 없이 빠르게 구현 가능한
  deterministic vision MVP를 설계했다.

## 2026-08-12 — CAD/Unity 배치 데이터를 로봇 recipe로 변환

- Unity prefab의 중첩 transform, OBJ 좌표계 handedness, `0.01` scale을 해석해
  기판 중심 기준 mm 단위 부품 슬롯을 자동 추출했다.
- 6종 recipe의 반복 배치를 JSON/CSV와 발표용 SVG로 생성해 수작업 좌표 입력
  오류를 줄였다.
- 요구 수량 25개와 모델 인스턴스 24개의 차이를 자동 검출하고, 누락된 갈색
  소형 칩 좌표를 임의 보간하지 않아 잘못된 자동 조립 명령을 차단했다.

## 2026-08-12 — 다중 카메라 계층형 품질검사 설계

- 이동형 D435의 정밀 RGB-D, 고정형 S22의 전체 전수검사, GoPro의 공정 감시를
  분리해 한 카메라의 시야·깊이·해상도 한계를 상호 보완했다.
- S22가 전체 25개 slot을 검사하고 불확실 ROI만 D435가 근접 재검사하는 구조로
  검사 시간과 정확도의 균형을 설계했다.

## 2026-08-12 — 상용 모바일 로봇 구동계를 컨베이어로 재구성

- 별도 stopper가 없는 한계를 영상 폐루프 감속·정지와 정지 후 board pose
  재계산으로 보완하도록 설계했다.

## 2026-08-13 — 장비 없이 검증 가능한 AI/Vision 서버 구축

- 3대 카메라 연결, YOLO 부품 검출, 조립 검사를 ROS 2 노드로 분리하고 명시적
  메시지 계약을 만들어 Main Server와의 통합 경계를 정의했다.
- Mock 검출기를 이용해 실제 카메라와 학습 모델 없이 정상 `25/25 PASS`와
  HBM 누락 `24/25 FAIL`을 재현했다.
- 검사 규칙 단위 테스트 4개를 통과했으며 모델이 없는 경우에도 서버가 종료되지
  않고 상태 토픽으로 준비 여부를 알리도록 설계했다.

- 향후 컨베이어 도착 감지와 조립 후 전수검사를 위한 S22 고정형 비전 입력 경로를
  실제 장비로 확보했다.
