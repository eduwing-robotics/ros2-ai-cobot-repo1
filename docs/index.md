# 문서 안내

이 문서 모음은 오래 유지되는 프로젝트 정책과 시스템 설계, 구현된 public API만 현행 기준으로 다룹니다.

## 현행 기준

| 문서 | 소유 내용 |
|---|---|
| `AGENTS.md` | 작업 범위, 책임 경계와 변경 정책 |
| [시스템 아키텍처](architecture/index.md) | 세 계층, 생산 불변 조건, 완료·실패와 데이터 경계 |
| [공개 API 목록](API.md) | 구현된 API 문서의 단일 목차 |
| 컴포넌트 README | 한 컴포넌트의 역할과 공개 실행 진입점 |
| 제공 컴포넌트 API 문서 | endpoint, payload, 오류와 완료 의미 |

실행 코드, IDL과 기준 DDL이 구체 계약의 원본입니다. 문서는 이 원본을 설명하며 구현되지 않은 이름이나 미래 구조를 미리 예약하지 않습니다.

## 문서 경계

- 시스템 의미와 책임은 아키텍처 문서 한 곳에서 설명합니다.
- 구체 통신 식별자와 메시지 형식은 API 문서에만 기록합니다.
- Real·Mock 표기는 구현이나 공개 경계가 실제로 갈리는 경우에만 사용합니다.
- production 데이터 계약은 공통 기반이며 별도 실행 컴포넌트나 backend로 표현하지 않습니다.
- 설치·실행 절차는 해당 진입점을 소유한 컴포넌트 README 한 곳에서 관리합니다.

## 기록 문서

`reports/`는 특정 시점의 조사와 검증 결과, `archive/`는 폐기된 설계와 계획을 보존합니다. 두 폴더는 현행 설계의 근거나 탐색 목차가 아닙니다.
