# Farino_AIO

FR5 협동로봇의 조립 작업과 Mock 시나리오를 모아 둔 작업 공간입니다.

## 현재 구현된 기능

- FR5 로봇 모형과 기본 제어 자원
- HBM 조립체 Mock 조립 시나리오
- Mock 생산 이력 기록 경로
- 카메라·보정·Pick & Place 참고 작업 파일
