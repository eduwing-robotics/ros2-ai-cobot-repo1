# 저녁 트레이 검출 안정화 — 2026-09-11

## 확인한 원인과 수정

IND 2번은 위치 검출이 사라진 것이 아니라 YOLO segmentation 점수가 낮았다. 약 32초·50개 결과에서 중심 변동은 0.05px 이내였지만 점수는 0.347~0.486이었다. 다른 IND는 0.85~0.91이었다. 자동노출은 켜져 있었으나 조명이 단독 원인이라고 입증하지 않았다.

기존 PM·VRM·HBM에 있던 추가 해상도 검사를 IND에도 적용했다. 기본 640 검사에서 약한 검출만 960 결과와 대조한다. 중심 3px, 각도 3도, 크기 0.8~1.2배, 깊이 2mm 이내의 유일한 대응과 기존 품질 기준을 모두 만족해야 교체한다. 새 부품을 만들거나 신뢰도 숫자만 올리지 않는다.

실제 수정 후 IND 2번 원 점수 0.3277에 대해 추가 검사 0.8529가 나왔고 중심 차이는 0.1253px였다. 안정화된 IND 2번 점수도 0.875로 확인됐다.

VRM은 2mm 전체 XYZ 변화로 실패했으나 기존 오류 기록에는 축별 값이 없었다. 후속 정지 관측에서는 영상 중심보다 Z 흔들림이 두드러졌다. GPU·HBM에만 있던 5x5 내부 마스크 깊이 측정을 VRM에도 적용해 경계의 트레이 바닥 혼합을 줄였다. 유효 내부 깊이가 부족하면 기존의 제한된 대체 측정 경로를 따른다. 기존 2mm 이동 거부와 3도 회전 거부 기준은 유지한다. 다음 오류에는 dXYZ 및 이전·현재 깊이값을 함께 기록한다.

## 검증과 배포

- 최종 전체 회귀 테스트 851개 통과(41.28초).
- 수정 후 32초·49개 관측에서 VRM 1~5번의 Z 범위는 각각 0.015/0.502/0.010/0.507/0.011mm였다. 이는 관측 구간 수치이며 과거 실패의 재현 시험은 아니다.
- 검출기와 API 서버 재시작 완료. 자동노출·노출·게인 설정은 변경하지 않았다.
- 실제 현재 영상에서 25개 촬영 품질 검사와 진단 스냅샷 변환 완료: 7.797초. 관측 영상 나이 0.333~1.251초.
- 실제 VRM 5개 정밀 보정 완료(exit 0). 로봇 이동 없음.
- 신뢰도 미달·기하 불일치 재검출 거부, 경계 깊이 오염 배제, 센서 프레임 일관성 및 기존 안전 동작을 테스트했다.
