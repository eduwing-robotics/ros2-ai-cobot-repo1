# TrayHome 복귀 및 SMDView 하강의 단일 MoveL 실행

## 적용 결과

- TrayHome 상공 복귀: 기존 직선상 TCP 경유점 3개를 실행 정지 지점에서 제외하고 한 번의 MoveL로 도착한다. 이미 단일 MoveL이던 짧은 복귀 5개도 그대로 유지한다.
- SMDView 하강: 원래 50mm 간격의 모든 지점에 대한 IK 사전 검사를 유지하고, 실행은 최종 하강의 기존 10% 속도로 한 번의 MoveL로 한다. 전체 하강이 저속이므로 중간 고속 구간은 사라진다.
- 파지 직후 안전 상승, 상공 도달 확인, 최종 TrayHome 도착·하강·촬영 확인과 그리퍼 동작은 유지한다.
- 다른 이동의 블렌딩 설정, 집기/배치 목표, 그리퍼 레시피, 촬영 종점은 변경하지 않는다.

## TrayHome 직선 경로 검증

기존 tray_after_raise 이후의 두 중간점과 tray_after_travel이 정확히 동일 높이의 직선 및 동일한 회전 방향을 정의하는지 확인한다. 새 경로는 10mm·5도 이하 간격으로 IK를 계산한다. 모든 샘플의 소프트리밋 여유와 J6 범위를 검사하고 인접 샘플의 관절 변화량을 10도 이내로 제한한다. 원래 종점 IK 분기도 동일해야 한다.

일부 SMD의 기존 전체 J6 복귀 회전량은 95도를 넘는다. 이것은 세 명령으로 나누어 실행할 때에도 존재했던 총 회전량이다. 단일 MoveL에서는 이 총량을 단일 관절 점프와 동일하게 해석하지 않고, 전체 직선의 연속 IK 샘플로 검증한다. 일반 MoveJ의 기존 95도 구간 제한은 변경하지 않았다. 검증 실패 시 중간 경유점을 무조건 생략하지 않으며 실행 전에 실패한다.

최근 성공 실행 0bf5780c-d6bf-4d01-b949-1365c6614164의 25개 복귀 모두 단일 MoveL 계획 검증에 통과했다. 총 관절 회전량 최대 105.456627도, 인접 검사점 변화량 최대 5.905250도였다. 목표 자세와 최종 관절 분기는 유지됐다.

## SMDView 하강 검증

최근 실행에서 11개 전체 경유점 중 하강 명령 6개를 한 개로 통합해 실제 실행 경유점은 6개가 된다. XY·자세가 동일한 수직 하강만 통합하고, 통합 명령의 시작→끝 관절 변화도 기존 95도 검사에 통과해야 한다. 검증 결과 최대 39.923843도였다. 기존 중간 검사 지점은 preflight.camera_descent.validated_samples에 저장한다.

## 테스트 및 반영

관련 회귀 테스트 174개 통과. 설치본 기준 관련 테스트 76개도 통과했다. 25개 TrayHome 복귀 및 SMDView에 대해 실제 제어기의 읽기 전용 IK 검증을 수행했다. 로봇 API 설치 및 재시작을 완료했다.

이 작업 중 로봇 이동과 그리퍼 명령은 전송하지 않았다. 실제 속도감과 부드러움은 다음 실기 운전에서 확인해야 한다.
