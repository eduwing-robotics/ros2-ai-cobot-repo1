## 5. 카메라 이동 시 트레이 추적

초기 섹션 선은 화면 픽셀에 고정돼 카메라가 움직이면 트레이에서 벗어났다.
이를 기준 사진과 현재 영상의 SIFT 특징점 및 Homography 정합 방식으로
수정했다.

동작:

- 카메라 이동/회전 시 트레이 위치와 원근을 다시 계산
- 섹션 사각형을 현재 트레이 위치로 변환
- 정합 실패 시 잘못된 선을 표시하지 않음
- 실패 문구: `TRAY NOT REGISTERED`
- 축소 영상에서 정합하고 원본 해상도에 적용
- 여러 Homography 꼭짓점의 중앙값으로 흔들림 감소

파일:

- `vision_assembly/scripts/view_tray_sections.py`
- `vision_assembly/run_tray_sections_view.sh`

실행:

```bash
/home/juchan-yoon/FR5_robot_control/vision_assembly/run_tray_sections_view.sh
```

화면:

```bash
source /opt/ros/jazzy/setup.bash
ros2 run rqt_image_view rqt_image_view /vision/tray/sections_image/compressed
```

오늘 마지막 확인 시 정합은 약 50개 이상의 RANSAC inlier로 `TRACKING`
상태였다.

파일:

- `vision_assembly/run_tray_part_detection.sh`

출력:

- `vision_assembly/data/tray_detections_last.json`
- `vision_assembly/data/tray_detections_stable_last.jpg`
- ROS Topic: `/vision/tray/detections_image/compressed`

실행:

```bash

```

화면:

```bash

ros2 run rqt_image_view rqt_image_view /vision/tray/detections_image/compressed
```

검출 항목:

- 중심 픽셀
- 트레이 기준 중심 픽셀
- 회전각
- Depth
- Camera XYZ
- FR5 Base XYZ
- 반복 관측 프레임 수
- CAD 면적 일치 점수

시간 안정화:

- 최대 최근 40프레임 사용
- 같은 플랜지 자세에서 촬영된 이력만 사용
- 4프레임 이상 반복 관측된 부품을 안정화 결과로 채택
- 부품 크기별 추적 반경 적용
- 종류별 목표 수량을 초과한 중복 검출 제거

최종 확인:

- VRM 5/5
- Power Module 4/4
- Inductor 2/2
- SMD Capacitor 5/5
- GPU 1/1
- HBM 8/8
- 합계 25/25

JSON에서는 순간값 `detections`가 아니라 `stable_detections`를 다음
단계 입력으로 사용한다.

## 7. Camera 좌표에서 FR5 Base 좌표 변환

활성 Hand-Eye 파일:

- `calibration/data/handeye_result.json`
- 선택 방법: DANIILIDIS
- Euler convention: `xyz`

변환 체인:

```text
p_base = T_base_flange @ T_flange_camera @ p_camera
```

Fairino 상태 서버:

```bash
source /opt/ros/jazzy/setup.bash
source /home/juchan-yoon/FR5_robot_control/robot_ws/install/setup.bash
ros2 run fairino_hardware_v3_9_7 ros2_cmd_server
```

상태 토픽:

```text
/nonrt_state_data
```

확인된 상태 주기는 약 95 Hz다.

안전 처리:

- 영상 검출과 로봇 상태 수신을 별도 ROS 실행 스레드로 분리
- 로봇 상태가 오래됐으면 `NO_FRESH_ROBOT_STATE`
- 로봇 자세가 안정되지 않았으면 `ROBOT_MOVING`
- 트레이 정합 실패 시 `TRAY_NOT_REGISTERED`
- 정상일 때만 `VALID_COORDINATES_ONLY`
- `robot_motion_authorized: false`
- 이동 및 그리퍼 명령은 전혀 보내지 않음

상태 스트림에 비현실적인 순간 점프가 있어 연속 샘플 점프 필터를 추가했다.
검출 이력에는 당시 플랜지 자세를 기록하고 현재 자세와 일치하는 데이터만
좌표 안정화에 사용한다.

최종 확인:

- 안정화 부품: 25개
- Base 좌표: 25개
- GPU Base 좌표 5회 범위:
  - X: 0.001 mm
  - Y: 0.091 mm
  - Z: 0.001 mm

마지막 Base 좌표 전체 범위:

- X: 약 -788.563 ~ -505.243 mm
- Y: 약 -218.244 ~ 107.919 mm
- Z: 약 -48.751 ~ -40.017 mm

위 범위는 측정 시점에 따라 조금 달라질 수 있다. 현재 Base XYZ는 부품 윗면의
측정점이며 로봇 TCP를 바로 이동시킬 목표점이 아니다.
