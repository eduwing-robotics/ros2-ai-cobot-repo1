## Git에 포함하는 최소 기준 (2026-09-08 정리)

위 설명은 현장 PC의 전체 보관본을 설명한다. Git에는 이 README, runtime.json, criteria_and_completed_slots.json 및 런처가 비교하는 files/ 아래 여섯 설정 JSON만 포함한다. 전체 manifest/camera_runtime/영상/모델/일회성 복구 스크립트는 현장 보관본에만 있다.
