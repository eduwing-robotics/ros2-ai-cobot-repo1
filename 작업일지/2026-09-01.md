## 2D 슬롯 변환 문제와 근본 해결

- 기존 방식은 화면 픽셀을 과거 수동 좌표 3개에 맞춘 2D affine 변환이라 기판의 미세 이동·회전·깊이 변화에서 오차가 누적됨을 확인.
- 슬롯별 재티칭 방식은 기판이 움직일 때 다시 틀어지므로 폐기하고, 네 자연 홀과 aligned depth로 현재 기판의 3D 자세를 계산하는 `track_board_pose_3d.py`를 추가.
- 처리 흐름:
  1. 컬러 영상에서 네 홀을 일관된 조합으로 검출.
  2. 홀 주변 depth annulus로 기판 평면을 robust fitting.
  3. 각 홀 중심 ray와 평면의 교점을 계산.
  4. 실제 홀 좌표에 Kabsch 강체 정합하여 Camera→Board 계산.
  5. 현재 Flange와 hand-eye를 결합해 Base→Board 산출.
  6. 기판 mm 좌표의 모든 슬롯을 Base 좌표로 변환.
- 토픽:
  - 상태/전체 슬롯: `/vision/board/pose_3d/status`
  - 선택 슬롯 표면 자세: `/vision/board/target_surface_pose_3d`
- 3D 추적기는 `dry_run=true`, `robot_motion_authorized=false` 상태로 좌표만 발행하며 직접 로봇 명령을 보내지 않음.
- 위험한 구형 2D 타깃은 `/vision/board/target_pose_legacy_unvalidated`로 분리.
