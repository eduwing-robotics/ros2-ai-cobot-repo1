- 축소 연속 사이클이 전부 성공하고 새 frozen snapshot/plan의 25개 좌표,
  회전, Z, 그리퍼 값, 속도를 검토한 뒤에만 25개 전체 사이클을 허용한다.
- 기존 25개 실패 실행에서처럼 한 부품을 못 잡았는데도 나머지를 계속 진행하는
  동작은 금지한다.

## 내일 이후 코드 우선순위

1. Depth timestamp가 일정 시간 갱신되지 않으면 board target을 invalid 처리하고
   명확한 `CAMERA_NOT_READY` 또는 stale-depth 오류를 내는 watchdog을 추가한다.
2. VRM/Inductor/Power Module에도 SMDView와 같은 FinePickView를 추가해 근접
   화면의 X/Y/yaw를 최종 권위값으로 사용한다.
3. Place 직전 실제 slot edge 또는 fiducial을 재검출하고 가능한 경우 local
   pixel error→robot XY correction을 1~2회 반복한다.
4. post-grasp 확인과 post-place 존재/안착 확인을 Backend 완료 callback의
   필수 조건으로 연결한다.
5. PCB 지그를 보강해 release 높이나 접촉으로 기판이 밀리지 않게 한다.
6. 2번 이후 데이터가 쌓이면 부품 종류별 고정 bias와 위치별 spatial residual을
   분리한다. 검증 없이 하나의 전역 X/Y offset을 모든 종류에 적용하지 않는다.
7. 위 조건이 충족되기 전에는 Real Backend의
   `enable_hardware_execution=true`를 사용하지 않는다.
