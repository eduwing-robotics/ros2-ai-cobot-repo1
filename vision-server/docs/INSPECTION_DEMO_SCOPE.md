# 시연용 비전 검사 기준 — 2026-09-08 고정

25개 슬롯을 대상으로 아래 범위를 사용한다. **검사 범위 합의이며 모델 성능 인증이나 PASS/FAIL 권한 승격은 아니다.**

| 결과 항목 | 검사 기준 |
|---|---|
| 부품 누락 | 지정 슬롯에 부품이 없음 |
| 방향 오류 | GPU/HBM 기준점, 인덕터 검정 표시 또는 지원하는 부품 방향이 잘못됨 |

| 표면 이상 | 검증된 촬영 조건에서 확인되는 뚜렷한 긁힘·손상 |

미세 턱걸림, 정확한 1mm 여유 측정, 영상에서 구분하기 어려운 미세 크랙은 **확정 검사 성능 주장 범위에서 제외**한다. 제외·미검증 항목은 정상 처리하지 않는다. 기존 필수 검사 단계를 제거하거나 무시하여 전체 PASS를 만들지 않는다.

## 최종 판정

VRM 위치 기준 변경(사용자 승인): 슬롯 안에 완전히 안착하면 중앙·좌우 치우침은 허용한다. 우측 벽 1mm 공정 여유만을 근거로 한 RIGHT 경고는 검사 후보에서 제외한다. 원래 측정값은 JSON에 보존하며 로봇 충돌 방지 조건은 변경하지 않는다. 슬롯 이탈·회전·턱걸림 검사 경로는 유지하되, 실제 안착을 영상으로 검증하지 못하면 UNKNOWN이다. 이번 변경은 완전한 슬롯 내부/높이 측정 기능의 구현 또는 인증이 아니다.

- PASS: 기존 융합 계약의 모든 필수 검사가 검증·가용 상태이고 정상.
- FAIL: 검증된 판정 권한을 가진 검사에서 불량 확인.
- UNKNOWN: 후보·저신뢰·경계값·검사 불가·상충 상태.

UNKNOWN 처리 합의는 **추가 촬영 1회(총 최대 2회), 이후 보류**이다. `triggered_inspection_once.py`에 재촬영 루프를 연결하고 모의 테스트했다. PASS/FAIL은 재촬영하지 않으며 `--skip-capture`는 카메라를 켜지 않는다. 각 시도 경로는 로컬 event의 attempts에 보존하고, 최종 UNKNOWN이면 recommended_action=HOLD를 기록한다. HTTP 판정 enum·URL은 변경하지 않는다. 실행 중인 API 서버도 다음 요청에서 새 자식 스크립트를 읽으므로 검사 소요 시간이 늘어날 수 있다.

이 로컬 HOLD 권고는 실제 설비 정지 명령이 아니다. Sequencer가 UNKNOWN을 받아 해당 Unit을 보류하는 실설비 연동은 아직 검증 전이다. 이미 UNKNOWN 재시도 정책이 있는 호출자는 `--unknown-recaptures 0`을 사용하도록 실행 구성을 합의해 중복 재시도를 피해야 한다. 보류는 불량 확정이 아니다.

### 모의 연동 검증 완료 범위

실제 요청 저장소와 재촬영 파이프라인을 연결하고 촬영·추론만 모의 처리하여 다음을 확인했다: 재촬영 중 같은 ID 요청은 RUNNING을 반환하며 새 검사를 만들지 않음, 다른 검사 ID는 busy 거절, 두 촬영 후 동일 job_id/unit_id/inspection_id에 최종 결과 저장, 저장소 재시작 후 같은 ID 재요청도 재촬영하지 않음. UNKNOWN→UNKNOWN/PASS/FAIL을 각각 확인했다. 실행 subprocess 어댑터·HTTP 통신·팀원 Sequencer·실제 설비는 이 테스트 범위가 아니다.

## 현재 제한과 운영

### 2026-09-08 소프트웨어 검증 결과

- 검사·재촬영·결과 내보내기·API·서버 묶음 관련 Python 테스트 368개 통과, 결과 화면 Node 테스트 1개 통과.
- 임시 localhost HTTP 서버에서 인증 거절, 요청 수락, UNKNOWN JSON 조회, PNG 바이트·해시 전달, 변조 이미지 거절을 확인하고 서버를 종료했다. 촬영·추론은 모의 데이터이며 팀원 PC와 통신한 결과는 아니다.
- 실제 Runner는 모의 자식 프로세스로 최종 시도 결과 선택과 실패/시간 초과 처리를 검증했다. 실제 장비 프로세스 종료 보장은 별도 현장 확인 대상이다.
- 아직 남은 현장 검증은 실제 S22 요청 1건의 최대 2회 촬영, 팀원 Sequencer의 동일 Unit 결과 수신 및 UNKNOWN 보류이다. 자동 테스트 통과는 모델 정확도 또는 확정 PASS/FAIL 권한을 뜻하지 않는다.

현재 미검증 후보의 `ADVISORY_ONLY`와 최종 `UNKNOWN`은 유지한다. 히트맵·위치 경고는 증거 후보이며, 경고가 없다고 PASS는 아니다. HBM 핀 검사 가용성, SMD 미세 안착, VRM 실측 여유 검증을 완료한 것으로 설명하지 않는다.

지금부터 시연 범위를 늘리는 임계값 조정·재학습은 중단하고, 실제 확인된 사례와 제한사항을 함께 제시한다. 재현 가능한 실행 오류는 별도로 수정할 수 있다. 정상/불량 정답은 실제 배치 확인으로 기록하며 결과에 맞춰 변경하지 않는다.

팀원 API·식별자·JSON/PNG 전달 계약·불량 코드 매핑은 변경하지 않는다. 범위 JSON의 category는 내부 설명용이며 새 전송 코드가 아니다. 새 설정: `vision_assembly/config/inspection_demo_scope.json`. 기존 판정 계약: `vision_assembly/config/inspection_fusion_contract.json`.
